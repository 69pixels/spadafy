A shift, from sign-in to sign-out

  1. Sign in

    At a shared workstation, with the authentication methods your policy requires.

    • Badge tap
    • Password or PIN
    • MFA where required

  2. Application access

    Single sign-on into supported clinical applications, validated with their owners.

    • Application SSO
    • Role-based access

  3. Workstation movement

    Locking, user switching and reconnecting to a virtual desktop as clinicians move.

    • Lock and switch user
    • Desktop reconnect
    • Reauthentication

  4. Session ending

    Sign-out and locking behave as designed, so the next person starts clean.

    • Sign-out
    • Auto-lock
