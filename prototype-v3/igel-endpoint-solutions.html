Endpoint services

From a compatibility check to centrally managed devices. Benefits are tied to the configurations we test with you.

Device and workflow
compatibility

  • Review devices, desktop platforms, applications, peripherals and connectivity.
  • Check display, network, authentication, printing, scanning and audio/video requirements.
  • Identify suitable devices, configuration dependencies and items requiring further testing.

Guided evaluation
and pilot deployment

  • Configure a representative pilot with agreed devices, applications and user workflows.
  • Test startup, authentication, desktop or application launch, reconnect, peripherals and communications applications.
  • Document tested configurations, results, adjustments and limitations affecting rollout.

IGEL OS deployment
and device reuse

  • Install IGEL OS on supported devices, including suitable existing hardware selected for reuse.
  • Prepare devices, access clients, management registration and configuration assignments.
  • Plan phased rollout and recovery arrangements.

Centralized
configuration and updates

  • Configure IGEL Universal Management Suite (UMS) to organize endpoints and apply consistent settings.
  • Set device profiles, desktop connections, network settings, certificates and administrative permissions.
  • Define how configuration changes and software updates are tested and deployed.

Desktop and
authentication integration

  • Integrate supported desktop clients with the agreed desktop-delivery and authentication environment.
  • Configure Imprivata authentication, badge access, reconnect and shared-workstation behavior where included and supported.
  • Validate the full combination of endpoint, client, authentication method, peripherals and user workflow.
